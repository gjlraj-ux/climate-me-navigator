How to use

Answer the four stages in order. Each answer tightens the constellation at Stage 4. You can jump ahead at any time — incomplete stages will show as "not yet answered" and the ranking will use fewer signals.

How fit is scored

Each tool is tagged across six dimensions. Your answers are matched against those tags to produce a fit score. Hover any fit badge at Stage 4 to see the breakdown — this is deliberately transparent so the logic can be debated and improved.

What it isn't

Not a recommendation engine. The goal is to narrow a wide field to a smaller, defensible shortlist — the final call is yours and depends on country context the tool doesn't see.
